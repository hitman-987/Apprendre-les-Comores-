    Proposer une ressource

    Un livre, une vidéo YouTube, une randonnée, un bon restaurant, une étude… Ce site grandit grâce à ceux qui connaissent les îles.

    1. Remplissez le formulaire.
    2. Envoyez la proposition.
    3. Elle est vérifiée puis ajoutée au site.

    L'envoi passe par GitHub et demande un compte gratuit. Pas de compte ? Copiez la proposition et partagez-la avec l'équipe du site.

    Ce site rassemble des liens vers des ressources publiques. Les contenus appartiennent à leurs auteurs.

    Un lien cassé ? Signalez-le avec le formulaire.

    Assistant Comores

    Bonjour ! Posez-moi une question sur les Comores : une île, un lieu, une période, une personnalité, la langue, la cuisine…

    Je réponds à partir des ressources du site, et je complète avec une recherche sur le web quand le site n'en dit pas assez.
